# 首页自动刷新验证

- 默认开启：加载首页后杀掉 App 重开，应请求新首页。
- 关闭开关：加载推荐/热门后杀掉 App 重开，应恢复对应列表；抓包确认恢复时不请求首页接口（图片、角标请求允许）。
- 关闭时下拉刷新，应获取新内容，重启后恢复更新后的内容。
- 恢复后滑到底部，应从保存的下一页继续加载，不跳页。
- 切换账号：不能显示上一账号的快照；退出登录使用游客快照或首次加载。
- 首次安装、快照不存在或损坏：仍能正常首次加载；断网显示重试入口。
- 同一会话从后台返回或切换标签：不强制替换已有列表。
- 快速下拉刷新/加载更多：不能重置正在进行的分页游标。

Windows 上仅完成语法与 diff 检查；上述运行断言尚需 Release 真机验证。
