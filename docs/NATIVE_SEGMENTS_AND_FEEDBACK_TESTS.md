# 原生分段控件与视频互动反馈验证

## 变更

- 首页推荐 / 热门和 UP 主主页五个板块改为系统 segmented Picker。保留现有横向分页与空间滚动协调逻辑。
- 视频互动图标的弹跳及点赞震动由独立操作事件驱动；初始接口和收藏兜底接口回填禁用动画。
- 仍需通过 Xcode 编译及 iPhone 验证。Windows 语法解析不是类型检查，也不能验证实际动画。

## 真机测试

1. 首页点击推荐 / 热门，再左右滑动；确认选中项和内容一致，头像及消息按钮正常。低电量模式重复切换。
2. UP 主主页依次点五个板块，并左右滑动；上划到标签吸顶，再切换板块及回到原板块。确认顶部不跳、相对阅读位置保留、视频卡片不会误打开、左边缘返回有效。
3. 以大字号、浅色 / 深色模式查看标签，尤其投稿数量较多的 UP 主，检查标题和选中状态可辨认。
4. 打开已点赞、已投币、已收藏及三项都已操作的视频，等初始接口返回：图标静默亮起，不弹跳、不震动、数量不增加。离开再进入、收起胶囊再展开、切全屏再返回，不能重播操作动画。
5. 实际点赞 / 取消、投币（含同时点赞）、收藏 / 取消和长按三连：保留对应反馈。已投满不重复投币；三连部分失败按原有提示处理。
6. 点赞请求断网失败：回滚图标和数量，不再额外弹跳或震动；提示错误。未登录操作仍提示登录。
7. 用受控延迟让初始关系响应晚于用户操作返回，检查已操作字段不被旧初始状态覆盖。收藏兜底查询成功时同样不能播放初始动画。
