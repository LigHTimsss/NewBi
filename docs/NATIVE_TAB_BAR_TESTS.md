# 原生首页底栏验证

改为 iOS 系统 TabView；首页底栏不再使用自绘玻璃、双层图标或着色遮罩。页面内频道分段控件不变。

## 交互变化

- 底栏尺寸、选中效果和切页由系统决定，不保留自定义整页横移和呼吸光轨。
- 搜索使用系统右侧独立入口；点击后导航推入搜索页，搜索框随页面进入。当前栏目不切换，取消或侧滑返回原栏目；每次重新打开都是新的搜索页。键盘、历史和热搜在导航转场完成后激活。
- 动态使用系统“新”角标。重复点标签遵循系统行为，需要主动刷新时下拉刷新。

## 真机步骤

1. 普通及低电量模式，各连续点击、按住拖动切换底栏 20 次。检查选中图标与显示页面一致，无空白、残留高亮、无响应。
2. 在首页 / 动态下滑到中间，切到其它栏目再回来，检查内容和位置保留；我的页大字体仍可滚动，末尾内容不被底栏挡住。
3. 让彩色视频封面经过底栏后方，观察原生玻璃边缘；分别测深色、浅色、减少透明度、增强对比度。效果强度以系统设置和当前 iOS 版本为准。
4. 从三个栏目分别点右侧独立搜索按钮：搜索框随页面滑入，不应先切到空白页；转场结束后键盘、历史和热搜出现。输入搜索、进 UP 主主页、侧滑返回，再取消，应回原栏目。另测搜索页侧滑返回、侧滑一半取消、快速连点搜索：不能重复推入、选中搜索占位页或丢失底栏。
5. 开视频后收成迷你胶囊，切普通标签、进搜索、取消、进二级页面再返回：胶囊不覆盖底栏按钮；展开、关闭和全屏退出正常。
6. 有新动态时角标出现；切过去刷新后消失。未登录和退出账号时显示正确。
7. Instruments 对比低电量切换的 Animation Hitches / 主线程耗时；不能仅凭采用原生控件就断言无掉帧。

Windows 仅能做代码 / Swift 语法检查。必须在 Xcode 编译并用 iPhone 验证，本文不代表上述真机检查已通过。

参考：[Apple TabView](https://developer.apple.com/documentation/swiftui/tabview)、[采用 Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)。
